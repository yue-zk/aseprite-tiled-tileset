# Aseprite 原创瓦片与过渡增补

## 在落笔前定义接缝

- 确定格宽高、视角、捆绑方式和实际展示倍率。格大小来自目标地图，样例的 16×16 不是通用默认值。需要沿用既有图集时，先记录槽位、边距、间距、材质、方向以及哪些图块正在被引用。
- 画规则地表前，先列纯材质、长直边、内角、外角和确实需要的对角分割。对两个都已填色的角点地形，四个角各取一种材质，所以完整组合有 16 种；透明／未指定触点不是这两个材质之一。空白可起刷是强制项：另做各独立笔刷的实材质—透明过渡。单材质角点刷通常需覆盖 15 个非空角点组合，包含一张纯面。若承诺空白、草、泥在同层自由接刷，须在同一套角点规则里统一它们：80 个非空组合，其中 36 个包含三者，不能用三份配对规则代替。全空是地图空格，不是全透明占位瓦片。边规则、混合规则不能照搬这张表，也不必补那些没有约定用途的状态。
- 先定一致的边界：相邻两格必须在共享边的同一位置换色；边界纹理、暗边宽度和色阶也要连上。对角接触是连通还是分开，要明确选择并检查一个实际铺设例子，不靠偶然的颜色分布决定。只需呈现独特轮廓的地标优先做固定图章，不为凑全规则把造型削成通用刷。

## 在 Aseprite 建母版

1. 建立一帧、格对齐的图集；为容易修改的部分分层，例如底色、接边、纹理、装饰。先画纯材质和一条代表性边，再做内外角及对角情形；同一次增补使用同一套边缘和色阶。
2. 瓦片应在地图原尺寸可读。检查大色块、轮廓与纹理层次，避免每格都出现一样醒目的点；防止在铺图时产生明显的棋盘或重复网纹。透明装饰看它和不同底材叠起来的结果。保留足够留白，不靠模糊或插值缩放藏接缝。
3. 高岸、悬崖等明显高差先保留底层水或地表，再以独立透明图块画上层体量；检查上层锚点、遮挡与擦除后底材仍在。对照材质和设计需要决定上下层关系，不要求所有高差都做成 Wang。
4. 保存为 `.aseprite`，以 1× 导出 PNG，不裁透明边距、不自动重排。若目标 TSX 已经被其他地图引用，除非明确迁移引用，否则不移动原有槽位；新增放在已预留格或独立图集。保存后反查 PNG 尺寸、透明度和槽位，再用 Tiled 实刷。

导出可用 Aseprite 的另存为／导出，或以实际安装的 CLI 执行 `aseprite -b tiles.aseprite --save-as tiles.png`。导出 PNG 不是替换母版；安装路径不同就选本机可执行文件。单独记录不是原稿生成的外来素材，不将参考图裁切成原创瓦片。

## 样例槽位

图集是 4 列 × 66 行，格宽高均为 16 像素，没有间距和外边距。前四行按本地 ID 0–15 排列。四角按左上、右上、右下、左下对应位权 1、2、4、8；对应位为 1 时该角是草地，为 0 是泥土。两种对角瓦片用连续草地隔开泥土角。第 5–6 行的左侧 2×2 是石砌花坛，右侧四格为普通装饰：花、石、草、蘑菇。ID 24–51 是草地／透明、泥土／透明的两两过渡像素；ID 52–87 是草、泥、空白三者同格的接点。ID 88–262 是新增的碎石状态，ID 263 是未登记的图集补齐槽，不是画图用的空白。所有地形像素统一登记在同一个 Corner Set：空白 0、草地 1、泥土 2、碎石 3。加碎石后共有 255 个非空签名，其中 175 个含碎石；原有 ID 0–87 保持不变。制作交汇瓦片时四条边对齐既有两两过渡，内部画清三者交点，并保持透明角与透明边真实露底。用途和图块名称以 TSX 的 `role`、`name` 自定义属性为辨识辅助，刷子不依赖它们。
