# Tiled 图块集、地形集与展示地图

## 盘点与整理

1. **从源格出发。** 在现有 TSX/TMX 里核对实际图集、图块尺寸、边距、间距、外部引用、平铺用法和规则；不要根据单张截图推测格子在真实地图中的用途。按单格、完整图章、用法组合、地形刷记下原来源。若已有合法的动画帧和时长，整理时保留；仅凭画面相似不推断为动画。
2. **产出外部 TSX。** 在 Tiled 用正确格宽高从 PNG 建立外部图块集；整理既有 TSX 时保留未授权修改的图块属性、动画与 ID。现有图集仍可同时含普通瓦片和地形瓦片：只给后者标注相应地形触点。需要把同几块放成对象图章时，保留在示例 TMX 或明确导出对应图章，不假设 TMX 会注册编辑器个人图章。
3. **Terrain Set 选择接触方式。** 在图块集编辑器的 Terrain Sets 面板建集并标出触点。材质围绕格角连续（如本例）用 **Corner Set**；需要沿两格的共享边对接（如按边连接的道路）用 **Edge Set**；确实要同时约束边和角时用 **Mixed Set**。只标实际有像素、能自然接上的状态；不要用伪造的触点或加大变体概率来掩盖缺格。未指定触点和已命名的基础材质含义不同。样例的同层角点集用 0 表示空白触点，瓦片对应区域必须真透明；全空由空地图格承担。承诺多种地形在同一层自由互刷时，将空白及互接材质装入同一个 Terrain Set，同一格的三方、四方交汇也需要专用像素和对应签名。有多格定向结构或明显上下遮挡时，先确认是否更适合独立图章或分层。
4. **做一张可编辑展示 TMX。** 收集代表性连续长边、凹凸角、对角接触、各尺寸图章和真实组合，并明确可复制区域及需要同时选择的层。普通图块、规则矩阵和实际铺设各有展示区，避免把孤立的矩阵误当铺设效果。样例可以作为一个入口，也可以按交付要求只给 TSX 与 PNG；不让约定文件名成为刷子的依赖。

## 多格图章和组合

在演示地图选中完整格块再复制；记下对齐基准（如左上格或落地点）、尺寸、朝向、透明遮挡和连接接口。多层图章须复制必要层后再判定结果。连续摆放的一件物体是图章，几件不同用途的物体加上合适底材形成组合；有颜色替换、季节或少量纹理变化的同结构摆法可以作为同组变体，不靠它们凑出新的类型。角色、碰撞与引擎导入不在本流程内。

## 验收顺序

- **可搬移**：复制整包到新目录，确认 TMX 相对引用 TSX，TSX 相对引用 PNG；不要使用机器绝对路径。新图只添加 TSX 后也找得到 PNG。在重组源图时验证原有引用仍指向原来的像素。有翻转标志的 TMX GID 应按格式解码；TSX 的本地 tile ID 与 TMX 的 GID 不同，不直接互换。
- **规则完整**：检查触点与实际像素一致；对于样例，统一角点集覆盖 255 个非空签名，四个边槽均为 0。保留无碎石的 80 个签名，新加 175 个含碎石的签名。测试各材质直接起刷、草泥互刷、碎石跨草泥和透明边，以及同一格的三方、四方交汇，不能只查两两过渡。测试纯草、纯土以及长边、凸角、凹角、对角鞍点；在新图的当前层上刷，检查其他层未被改动。对于已经有缺格的素材，记录缺的是哪一组触点、是否需要补画像素，不用图章冒充地形刷。
- **实际打开和观察**：按主入口的强制门槛，从独立地图的真正空白处用 Terrain Brush 起刷、扩张、改形、擦回空白，不得先铺任何材质。在同一层、同一集内从空白画草，刷出泥心草边，再让泥土穿过草的透明边，检查是否出现「缺少地形过渡」、硬切或漏角。普通格和完整图章另行验证。用原尺寸及整数倍观察可见格缝、锚点、透明边和层间遮挡。可以用 Tiled 自带的 `tmxrasterizer showcase.tmx showcase.png` 生成检查图；栅格化只证明地图可读取和渲染，不能替代编辑器里实刷。

样例展示图左侧是实铺，右上是 ID 0–15 的 4×4 地形矩阵（从左到右、从上到下，中间有空格便于辨认），右下是物件陈列。装饰与底层地表分开，擦除装饰即可检查底材保持；最上方是全空练习层，中下排左侧展示泥心草边，右侧展示泥土接到透明外缘的三方交汇。最下排左侧展示碎石独立起刷和挖洞，右侧展示碎石、草、泥、空白同格过渡。
